# galaxy-multiuser
Magisk/KernelSU module for enabling Android multi-user properties on Samsung Galaxy devices.

This module sets limit to 4 users for stability, you can change that by editing service.sh and system.prop files and compressing them again.

**Instalation**
- Download galaxy-multiuser.zip and go to magisk/KernelSU manager
- Click modules then install from storage
- Choose the zip file you just downloaded and click Yes
- Reboot when prompted.
